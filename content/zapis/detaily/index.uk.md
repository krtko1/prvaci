{{< collapsible-section "Як проходить день запису?" >}}

Очний запис складається зі спільної лекції про навчання на FMFI, після якої, відповідно до розкладу,
розміщеного біля *študijného oddelenia* (ŠO, навчальний відділ), студенти по черзі заходять до окремих кабінетів для електронної реєстрації.

{{< /collapsible-section >}}


{{< collapsible-section "Коли я маю прийти на запис?" >}}

На очний запис приходь лише у визначені для тебе дату й час (див. [розклад]({{< var "events.zapis.link_harmonogram" >}})).
Якщо у винятковому випадку ти не можеш прийти на жоден із трьох термінів очного запису, додатковий запис відбудеться {{< var "events.zapis.datum_nahradny" >}}.

{{< /collapsible-section >}}


{{< collapsible-section "Що потрібно принести із собою на запис?" >}}

- закордонний паспорт
- фотографію обличчя розміром 4×6 см
- роздруковані підтвердження про проходження онлайн-навчання з BOZP (bezpečnosť a ochrana zdravia pri práci) a OPP (ochrana pred požiarmi)
- роздруковану заповнену заяву під чесне слово (більше інформації знайдеш в електронному листі від пані продеканки)

{{< /collapsible-section >}}


{{< collapsible-section "Особливий порядок для неповнолітніх та умовно зарахованих студентів" >}}

- для **неповнолітніх**: до кабінету *študijného oddelenia* потрібно прийти разом із законним представником або уповноваженою особою.
Завчасно перед очним записом потрібно заповнити форму, про яку повідомляється в електронному листі від факультету.
Для неповнолітніх студентів передбачено один із трьох днів для запису
- для **умовно зарахованих**: ти можеш відвідати спільну вступну лекцію, але після неї потрібно звернутися до керівниці *študijného oddelenia* в кабінет № 7 для отримання подальшої інформації.
Без подання атестата про повну загальну середню освіту тебе не може бути зараховано на навчання.

{{< /collapsible-section >}}


{{< collapsible-section "Що я отримаю під час запису?" >}}

- *zápisný list* (див. нижче)
- студентський квиток (відповідно до заповненої електронної форми, див. [Після зарахування; Документи, обов’язки](../../po_prijati/povinnosti))
- довідку про навчання (*potvrdenie o štúdiu*)

{{< /collapsible-section >}}


{{< collapsible-section "На записі я отримав zápisný list, що це?" >}}

<!-- Todo: change link to ukrainian version when it's ready  -->
Вже перед записом тобі буде створено *zápisný list*, що складається з обов'язкових предметів
(*povinné predmety*, позначаються літерою A) для першого року твоєї навчальної програми (*študijný program*),
та факультативного предмета (*voliteľný predmet*, позначаються літерою C) "Anglický jazyk (1)"
(предмети Anglický jazyk (2), (3) і (4) рекомендуємо записати згідно з результатами онлайн тесту з англійської мови, див. частину [Po prijatí; Dokumenty, povinnosti]({{< ref path="/po_prijati/povinnosti/index.sk.md" lang="sk" >}})).
Цей *zápisný list* можеш змінювати під час перших двох тижнів кожного семестра (так званий **opravný zápis**) через [AiS2](https://ais2.uniba.sk) або надбудову [Votr](https://votr.uniba.sk).
Більше інформації про *zápisný list* див. у розділі [Štúdium; Študijný plán a zápis predmetov]({{< ref path="/studium/studijny_plan_zapis/index.sk.md" lang="sk" >}}).
