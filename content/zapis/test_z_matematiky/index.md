Fakulta ponúka online test z matematiky, ktorý je odporúčaný pre študentov prijatých na konverzný študijný program (BINk, DAVk, INFk, FYZk, OZEk, TEFk). V prípade dobrého výsledku (teda dostatočného matematického základu) je vhodné zvážiť prestup na klasickú (nekonverznú) verziu študijného programu. V takom prípade kontaktuje <rostas@fmph.uniba.sk>. Tento test **nie je povinný**.

Dátum a čas sprístupnenia online testu: {{< var "events.test_mat.datum" >}} od {{< var "events.test_mat.cas_od" >}} až {{< var "events.test_mat.cas_do" >}} (na vypracovanie je max. {{< var "events.test_mat.cas_vypracovanie" >}} minút), na [tomto odkaze]({{< var "events.test_mat.link" >}}). Test je možné absolvovať **iba** v stanovenom termíne.
